Add `Tree` — a hierarchical tree menu with composable parts (`Tree`, `TreeItem`, `TreeItemTrigger`, `TreeItemLabel`, `TreeItemGroup`, `TreeItemCheckbox`, `TreeItemIcon`) and a data-driven `TreeView` wrapper. Supports expand/collapse, single selection, multi-checkbox, leading icons, and trailing slots (e.g. `Tag`), with roving-tabindex keyboard navigation and full WAI-ARIA tree roles. `TreeView` can virtualize long trees (`virtualized` + `height`) so thousands of nodes stay fast. Styled with `--ui-*` semantic tokens (the blue selection gamma). Initial version ported from `ui-legacy` and reconciled against the Figma "Tree" component set; design reconciliation of a dedicated token tier is pending.
