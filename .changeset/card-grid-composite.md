Add `CardGrid` — a config-driven card grid composite (`<CardGrid items renderItem />`) over the `Grid` + `Card` primitives. It lays a list of peer items out as uniform Cards in a responsive grid — a fixed responsive column count (`cols`) or an auto-filling track (`minColumnWidth`) — wrapping each item's content in a Card shell so catalog / gallery / picker tiles align and reflow consistently. An opinionated composite (see the opinionated-composites proposal). Initial version; design reconciliation pending.
