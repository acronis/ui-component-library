## 0. The `data-grid-config/index.ts` edit is atomic with the module

`_AssertEveryConfigRegistered` in that file fails to compile when a group is
declared on the registry maps but absent from the module array. That assertion is
F4's replacement for the old total-record `satisfies`, and it means **declaring
the group and registering the module cannot be split across two commits** — the
intermediate state does not merely fail for the unit, it turns
`pnpm --filter @constructor-lab/ui-react typecheck` red for the whole checkout.

U3 hit this for real: `columns-features.ts` declared `columnsFeatures` and staged
its manifest line as instructed, and the tree went red for everyone.

**Second reason the unit has to own the position, not just the line:** manifest
order drives the column fold, so position *is* placement. `detailExpansion` sits
between `actions` and `selection` so the expander lands **behind** the selection
checkbox — `[__select__, __detail__, …data, __actions__]`, which is what
`anatomy.yaml` specifies ("selection-column: leading checkbox; detail/tree/actions
are other system columns"). Applied at the wrong index the expander sits in front
of the checkbox. U2's tree expander has the same constraint.

**U1 therefore applied its own `index.ts` edit** (§1), and it is already in the
working tree. §2 is a genuine integrator edit with no such coupling. Awaiting the
team lead's ruling on whether this becomes the standing rule.

## 2. `packages/ui-react/src/components/ui/data-grid/index.ts` — integrator

The group's public config type has no route to package consumers otherwise:
`data-grid.tsx`'s re-export block is closed to units, which is the closure F4
bought. Until this lands, `DataGridDetailExpansionConfig` is reachable only
through the internal `data-grid-config` path, which is what U1's type test does.

**Append** to the `export { … } from './data-grid-config'`-adjacent block:

```ts
export {
  DATA_GRID_DETAIL_COLUMN_ID,
  type DataGridDetailExpansionConfig,
} from './data-grid-config';
```

`packages/ui-react/src/index.ts:28` is `export * from './components/ui/data-grid'`,
so the root barrel needs nothing.
