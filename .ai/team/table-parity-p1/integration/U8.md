## 5. Closed by Landing C — kept for the reasoning, which still holds

`data-table/behavior.md:365`'s "toggled exclusions emit against the authoritative
token without mutating it internally" is **not implementable from `server.ts`**.
Adjusting `excludedIds` needs the loaded row ids, and there is no route to them:
`resolve` would need `getRowId` in `reads`, which is the documented row-model
churn hazard; `DataGridControllerContext` carries `rows` but no id resolver; and
`controllerOptions` cannot contribute the `selection` slice because `state.ts`
owns `state`. The one place a row id is in hand at the moment of a toggle is the
selection column's `cell` renderer, i.e. `data-grid-config/selection.tsx` — so
that clause belongs with `selection.selectAll: 'all-results'`, which is a
different file with a different owner.

**Resolved.** The team lead authorised `selection.tsx` once U9 landed, and Landing C
put the delta at the toggle site exactly as predicted. The reasoning is kept because
it explains a shape a reader would otherwise find odd: `server.ts` publishes an
authoritative slice handler for `explicit` mode and deliberately **not** for
`all-results`, and that asymmetry is permanent, not pending.
