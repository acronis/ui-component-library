[`@spec-lab/tokens`](/packages/tokens) ships design tokens as CSS custom
properties (`--ui-*`). The **Primitives** (`css/primitives.css`), **Semantic**
tier (`css/semantics.css`), and each **component** tier
(`css/components/<Component>.css`) are all pulled in by the single
`@spec-lab/tokens/css` import (which `@spec-lab/ui-react/styles` bundles).

Values are shown for the `acronis` brand; most are `var(--…)` **references** onto
a primitive, and the primitive resolves via [`light-dark()`](/theming), so the
active color scheme picks the light or dark value at runtime. For more on how
brands and color schemes are delivered,
see [Theming](/theming).
