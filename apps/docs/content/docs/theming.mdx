## How themes work

Constructor Lab UIKit uses generated `--ui-*` CSS custom properties from
[`@constructor-lab/tokens`](/packages/tokens). You never hand-author theme values — they
are generated from the design system and resolved at paint time, so brand and
light/dark switches need **no rebuild** and **no extra imports**.

Everything ships in one bundle. `@constructor-lab/ui-react/styles` already includes it;
to consume the tokens directly, import once:

```css
@import '@constructor-lab/tokens/css'; /* primitives + semantics + every component tier */
```

Both axes are then switched by attributes on any ancestor (typically `<html>`):
brand via `data-brand`, light/dark via `data-theme`. The bundle carries every
brand (the default under `:root`, others as `[data-brand='…']` override blocks)
and both themes (via `light-dark()` on the primitive layer).

## Dark mode

Dark mode is built into the tokens via `light-dark()` + `color-scheme`. Toggle
the active scheme with `data-theme` (unset follows the OS preference):

```html
<html data-theme="dark"></html>
```

## Brand switching

Brand is an attribute, not an import or a class toggle — set `data-brand`:

```html
<html data-brand="deep-sky"></html>
```

Combine the two freely, e.g. `<html data-brand="deep-sky" data-theme="dark">`.

## Design tokens

Key CSS variables you can override:

| Variable                            | Purpose                |
| ----------------------------------- | ---------------------- |
| `--ui-background-surface-primary`   | Main page background   |
| `--ui-background-surface-secondary` | Secondary surfaces     |
| `--ui-text-on-surface-primary`      | Primary text color     |
| `--ui-text-on-surface-secondary`    | Secondary / muted text |
| `--ui-border-on-surface-border`     | Dividers and borders   |
| `--ui-background-brand-primary`     | Brand accent color     |

## Custom theme

Override any variable in your CSS:

```css
:root {
  --ui-background-brand-primary: #7c3aed;
}
```
