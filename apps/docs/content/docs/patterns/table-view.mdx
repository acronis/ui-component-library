The approved target shape for a records screen is a **`PageHeader`** (title +
primary action) plus one **`DataGrid`**. DataGrid owns the standard search,
filters, data states, and pagination; the pattern supplies domain columns,
data, configuration, and callbacks. Do not wrap it in duplicate table chrome.

<Callout type="warn">
  `DataGrid`'s grouped-config API has shipped, but the demo below still
  hand-composes an external toolbar with `DataTable` — a transitional workaround
  pending migration. It is not the approved target for new records screens;
  build those from one `DataGrid`.
</Callout>

See [Table component responsibilities](/guides/table-responsibilities#table-view)
for this pattern's current and target ownership boundaries.

## When to use

- A primary screen listing records the user browses, searches, filters, and
  paginates.
- A table that needs both free-text search (InputSearch) and discrete filters
  (Filter).
- Any place the app shows "all the Xs" as the main content of a route.

## When not to use

- Rows that need multi-select plus a bulk-action bar — use
  `data-table-bulk-actions`.
- A small, fixed set of rows with no search/filter/pagination — a plain `Table`
  is enough.
- Card-based catalog/gallery tiles rather than tabular rows — use `card-grid`.

## Current demo composition

This code mirrors the current demo only. Migrate it to `PageHeader` plus one
`DataGrid` (using its `toolbar`/`filters` config) — the grouped search/filter
configuration has shipped.

```tsx
function DevicesView({ columns, rows, onSearch, onCreate }) {
  return (
    <div className="flex flex-col gap-4">
      <PageHeader>
        <PageHeaderRow>
          <PageHeaderTitle>Devices</PageHeaderTitle>
          <PageHeaderActions>
            <Button onClick={onCreate}>Add device</Button>
          </PageHeaderActions>
        </PageHeaderRow>
      </PageHeader>
      <div className="flex items-center gap-2">
        <InputSearch
          className="max-w-xs"
          placeholder="Search devices…"
          onChange={(e) => onSearch(e.target.value)}
        />
        <Filter count={2}>Status</Filter>
        <Filter>Type</Filter>
      </div>
      <DataTable columns={columns} data={rows} />
    </div>
  );
}
```

## Guidelines

- Target one `DataGrid`; do not create separate engines for its body and chrome.
- Configure free-text search and discrete filters through DataGrid's
  `toolbar`/`filters` config; do not add a duplicate external toolbar.
- Keep the `PageHeader` so the screen has a title and a home for its primary
  action.
- If you need per-row selection, adopt `data-table-bulk-actions` — don't add
  bare checkboxes without the bulk-action bar.
