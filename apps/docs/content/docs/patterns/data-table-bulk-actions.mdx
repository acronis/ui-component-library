The approved target for row selection with bulk actions is one **`DataGrid`**
configured with selection and bulk actions. DataGrid owns the checkbox column,
selected count, contextual action bar, action overflow, and confirmations so
the body and controls always share one state engine.

<Callout type="warn">
  `DataGrid`'s selection + bulk-action config has shipped (and `useDataTable`
  lets a body and external chrome share one controller), but the demo below
  still renders `Table` primitives and pagination over one direct
  `useReactTable` instance. This is a transitional workaround pending migration,
  not the approved target.
</Callout>

See
[Table component responsibilities](/guides/table-responsibilities#data-table-bulk-actions)
for the transitional workaround and the target `DataGrid`-first boundary.

## When to use

- A table where users pick several rows and apply one action to all of them.
- Destructive or batch operations (delete, export, assign) across rows.

## When not to use

- A standard read-only or single-select records grid — configure `DataGrid`
  without bulk actions.
- One action per row — put a row action (menu / button) in a cell instead.

## Anti-patterns

- Using the self-contained `DataTable` **and** a separate `useReactTable` for the
  bar — their selection states diverge.
- Rebuilding selection checkboxes and the bulk toolbar around `DataGrid` — use
  the composite's built-in `selection` + `toolbar.bulkActions` controls.
- Leaving the bulk bar always visible — show it only while rows are selected.
- Hiding the selection count — always show "N selected" so the scope is clear.

## Current workaround

This code explains the existing demo. The `DataGrid` composite API has shipped;
prefer it for new work. This one-direct-instance approach remains valid only for
a specialized workflow the config cannot express — do not combine it with the
convenience `DataTable`, and do not treat it as the default:

```tsx
const [rowSelection, setRowSelection] = useState({});
const table = useReactTable({
  data,
  columns, // includes a checkbox 'select' column
  getCoreRowModel: getCoreRowModel(),
  getPaginationRowModel: getPaginationRowModel(),
  enableRowSelection: true,
  onRowSelectionChange: setRowSelection,
  state: { rowSelection },
});
const selected = table.getSelectedRowModel().rows;
```

Render the bulk bar only while `selected.length > 0`, wire **Clear** to
`table.resetRowSelection()`, render the grid from `table.getHeaderGroups()` /
`getRowModel()`, and pass the same `table` to the current pagination companion.
For standard grids, replace this composition with `DataGrid` selection +
`toolbar.bulkActions` configuration.
