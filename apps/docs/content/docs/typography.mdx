[`@constructor-lab/tokens`](/packages/tokens) emits the typography
scale as `.ui-typography-*` utility classes (in `css/semantics.css`), rather than
as `--ui-*` custom properties. Apply a class to set a complete text style —
font family, size, weight, line height, and letter spacing — in one place:

```tsx
<p className="ui-typography-body-default">Body copy.</p>
<h1 className="ui-typography-headings-display">Page title</h1>
```

Each row below renders a live sample with the parsed declarations applied
inline, alongside the class name and its metrics. Styles are grouped by family.
