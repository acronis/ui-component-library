## Usage

```tsx
import { ScrollArea } from '@constructor-lab/ui-react';
```

`ScrollArea` is a scrollable region built on the Base UI Scroll Area primitive.
Unlike a native `overflow: auto` element, its scrollbar is a **custom overlay**:
it floats over the content and reserves **no** layout space, so full-bleed
content (e.g. edge-to-edge selected rows in a sidebar) is never cropped by a
scrollbar gutter — on every OS and browser, not just where the platform provides
overlay scrollbars. The bar is hidden at rest and revealed on hover/scroll.

The all-in-one `ScrollArea` renders the viewport, content, and built-in
scrollbar(s); `orientation` (`'vertical'` default · `'horizontal'` · `'both'`)
selects which bars appear, and `'both'` also renders the corner. For custom
scrollbar placement, compose the exported `ScrollBar` part directly. The focused
viewport shows a `--ui-focus-brand` ring.

The thumb is **translucent**, because an overlay bar floats over content it does
not control: it mixes `--ui-background-inverse-primary` down to 40% alpha (60% on
hover), a token that is already near-black in light mode and white in dark, so
one token covers both themes. `tone="inverse"` switches it to
`--ui-glyph-on-brand-primary` (white, fixed in both themes) for a surface that is
dark in light mode too — a brand-colored sidebar, where the themed value would
paint near-black on brand. `SidebarPrimary` sets it for exactly that reason.

The bar is a **6px track held 2px off the viewport edges**, and the thumb grows
to **10px while pointed at or dragged** — a hairline that stays out of the way
until you aim at it, then becomes a target worth hitting. The growth is inward,
so the thumb's outer edge stays flush with the viewport edge and the bar never
shifts under the pointer.

> Design-pending v1: ported from the legacy shadcn-uikit `ScrollArea`.

## Examples

<DemoReact>
  <ScrollAreaDemo />
</DemoReact>

```tsx
<ScrollArea className="h-72 w-64 rounded-md border border-border">
  {longList}
</ScrollArea>
```

```tsx
// Both axes (also renders the corner)
<ScrollArea orientation="both" className="h-72 w-96">
  {wideTallContent}
</ScrollArea>
```

```tsx
// Over a surface that is dark in both themes
<ScrollArea
  tone="inverse"
  className="h-72 bg-[var(--ui-background-brand-primary)]"
>
  {longList}
</ScrollArea>
```

```tsx
// Compose the parts directly
import { ScrollArea, ScrollBar } from '@constructor-lab/ui-react';

<ScrollArea orientation="horizontal">
  {row}
  <ScrollBar orientation="horizontal" />
</ScrollArea>;
```

`orientation` and `keepMounted`) plus the same `tone`, for when the bars are
composed by hand rather than rendered by `ScrollArea`.
