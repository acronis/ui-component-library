## Usage

```tsx
import {
  AuthLayout,
  AuthLayoutCard,
  AuthLayoutLogo,
  AuthLayoutFooter,
} from '@constructor-lab/ui-react';
```

`AuthLayout` is a **composite** layout for authentication flows (sign-in /
sign-up / forgot-password / 2FA): a full-page centered surface that holds an
`AuthLayoutCard`. Inside the card, an `AuthLayoutLogo` is the top brand slot, the
form content is the card's children, and an `AuthLayoutFooter` holds the bottom
links. It is layout-only — drop your own `InputText`, `Button`, and links into
the slots. Surfaces use the shared `--ui-*` semantic tokens (`bg-background`,
`border-border`).

A sign-in screen:

```tsx
<AuthLayout>
  <AuthLayoutCard>
    <AuthLayoutLogo>
      <span className="text-base font-semibold">Sign in</span>
    </AuthLayoutLogo>
    <div className="flex flex-col gap-4">
      <InputText label="Email" type="email" placeholder="you@example.com" />
      <InputText label="Password" type="password" />
      <Button className="w-full">Sign in</Button>
    </div>
    <AuthLayoutFooter>
      <a className="underline underline-offset-4" href="#">
        Forgot password?
      </a>
    </AuthLayoutFooter>
  </AuthLayoutCard>
</AuthLayout>
```
