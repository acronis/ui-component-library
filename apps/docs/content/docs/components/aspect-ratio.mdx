## Usage

```tsx
import { AspectRatio } from '@constructor-lab/ui-react';
```

`AspectRatio` is a layout-only primitive: it constrains its box to a given
`ratio` (width ÷ height) using the native CSS `aspect-ratio` property, and its
child fills it. It carries no color tokens — style the child yourself. It's a
**design-pending v1** ported from the legacy kit.

## Examples

<DemoReact>
  <AspectRatioDemo />
</DemoReact>

Give it a width (from a parent or a `className`) and a `ratio`; size the child
`h-full w-full` (and `object-cover` for media):

```tsx
// 16:9 media, clipped with a radius
<AspectRatio ratio={16 / 9} className="overflow-hidden rounded-lg">
  <img className="h-full w-full object-cover" src="/cover.jpg" alt="Cover" />
</AspectRatio>

// Square (default)
<AspectRatio>
  <img className="h-full w-full object-cover" src="/avatar.jpg" alt="" />
</AspectRatio>
```
