Overview

One pnpm monorepo, four roles

A React component library, demo & docs apps, two design-data packages, and a build-tooling tier — organized into four top-level directories, each with a distinct job.

context/

📘 Instructions

Markdown read by both LLMs and humans — cross-workspace conventions, each workspace also has its own.

apps/

🚀 Applications

Deployed surfaces — the demo SPA and the docs site. Private.

packages/

📦 Published

Packages shipped to the npm registry — the libraries and design-data.

tools/

🔧 Tooling

Scripts that automate, translate & execute — e.g. token→CSS builds. Never published.

North star: ui-react (Base UI) is the one library teams build on; ui-legacy (shadcn) moves to maintenance / freeze with a defined deprecation path.

Architecture

The single pipeline

Figma is the upstream source of truth. Everything downstream is generated, validated, and committed — not hand-authored.

CONSUME

Runtime theming model: --ui-* custom properties + [data-theme] + light-dark(). A new Figma brand mode generates a new <brand>.css with no code change.

Development Process

One script vocabulary everywhere

Every workspace exposes the same script names. Run across all, or filter to one.

🔁 Per-workspace scripts

dev · build · test · test:watch · lint · lint:fix · typecheck · clean

Run as:

pnpm -r <name> — all workspaces, topological order

pnpm --filter <pkg> <name> — single workspace

🌳 Root-only scripts

  • format / format:check — Prettier across the tree
  • changeset / version / release — Changesets CLI
  • husky — lint-staged + typecheck (pre-commit)

Catalog block in pnpm-workspace.yaml is the single source of truth for shared dependency versions — bump in one place.

Development Process

Commit hygiene & quality gates

✍️ Conventional Commits

Format: <type>(<scope>): <summary> — enforced by commitlint on every commit and on PR titles.

  • feat · fix · chore · docs · refactor · test · ci
  • Scope = workspace or component feat(button): add loading state

🛡️ Pre-commit hook (Husky)

  • lint-staged — eslint --fix on staged TS/JS, prettier on JSON/MD/YAML
  • typecheck — pnpm -r typecheck across every workspace

Never --no-verify. Never --amend a failed-hook commit. Fix the issue, re-commit.

Published workspaces follow the Changesets workflow — commit .changeset/*.md alongside the code change it describes.

Roadmap · Decisions locked

The five decisions that frame everything

Direction

ui-react replaces ui-legacy

Legacy → maintenance/freeze; all new work (incl. the Table cluster) targets ui-react. Legacy gets security/critical fixes only.

Sequencing

Foundational-first buildout

Components ship bottom-up: primitives → composites → data/complex, so higher-order components always have their building blocks.

Theming

Generated, not hand-authored

Brand themes are generated CSS from tokens → tokens. --ui-* + [data-theme] + light-dark(). White-label = full Figma brand modes.

Timeline + a11y

Q3 2026, WCAG 2.1 AA

Usable base set by early Q3; v1 GA end of Q3. v1 = all basic Base UI + design-system components + selected complex (Table & friends).
